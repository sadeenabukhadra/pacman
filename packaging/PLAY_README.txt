PAC-MAN — LINUX ONEFILE
Run: bash play.sh
Help: bash play.sh --help
Custom config: bash play.sh /absolute/path/to/config.json
Movement: arrows or WASD. Other controls/rules are in Instructions.
Theme and display mode are in Settings.
Images, dependencies and default config are embedded in the executable.
Player data: ${XDG_DATA_HOME:-~/.local/share}/pacman-42/
Explicit absolute score paths in custom configs are respected.
The launcher creates no files beside the executable.
No separate Python installation is needed. Initial extraction may take time.
Build and test on the target Linux system. This is not a Windows executable.
