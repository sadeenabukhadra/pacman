PAC-MAN — LINUX

Extract the entire ZIP into a writable folder.
Keep all bundled files together.

Launch:
    bash play.sh

Movement: Arrow keys or WASD.
See Instructions in the main menu for controls and rules.
Use Settings to change the theme and display mode.

Edit config.json before launching to change game settings.
Scores and settings persist in the extracted game folder.
No Python installation is required to play.
